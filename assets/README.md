# Screenshots

Documentation screenshots of the app browsing its own wiki, used by the root [README](../README.md). They are not test fixtures: they are large and change with the UI. Fixtures for image tests live under `fixtures/` and stay tiny.

`wiki/assets/` holds identical copies so wiki pages can show them from inside the collection root (images outside it are not rendered, [ADR-0017](../wiki/decisions/0017-static-local-images-only.md)). Update both when retaking a screenshot.
